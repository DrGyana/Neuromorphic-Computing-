# Neuromorphic-Computing-
This repository contains the implementation used in the paper:
"Event-Driven Neuromorphic Computing for Scalable Energy-Efficient Cognitive Intelligence"

Authors: Sibun Parida, Jagjit Singh Dhatterwal, Chaitanya singla, Gyana Ranjana Panigrahi, Ramdas Khomane.

Requirements Python 3.11

Install packages

pip install -r requirements.txt

Run python main.py
